# include

Shared YAML fragments, merged into elements with the `(@)` directive.

| File | Holds | Included by |
|---|---|---|
| `aliases.yml` | source URL aliases (`github:`, `gnome:`, `pypi:`, …) | `project.conf` |
| `os-release.yml` | the identity generator: `/usr/lib/os-release`, the `/etc` symlink, `image-info.json` | `elements/oci/os-release.bst` |
| `fsdk-version.yml` | the freedesktop-sdk release, for `%{fsdk-version}` | generated by `just bst`; gitignored |

`fsdk-version.yml` is never hand-edited: `just bst` writes it from the pinned
freedesktop-sdk junction ref on every invocation, so the version has exactly one
source. Consume it inside a `variables:(@)` block — a bare top-level key is
rejected by BuildStream.
